# GenAI Assignment

This repository contains a collection of front-end web development assignments and mini-projects focused on HTML, CSS, Bootstrap, responsive design, and interactive user experiences.

## Project Overview

The projects in this repository were designed to build and practice:

- Semantic and structured HTML5 page development
- Responsive layout design with CSS3
- Bootstrap-based UI creation
- Interactive web applications using jQuery
- Integrated UI/UX design principles for a polished user experience
